# Citrus AutoFish для Horizon

Авто-рыбалка для **Horizon** — реализации Minecraft: Java Edition, переписанной на Rust. Мод использует собственный API Horizon и рассчитан на Minecraft 26.3. Это **не** Fabric/Forge-мод, не Bedrock-addon и не мод для обычного Java-клиента.

> **Статус:** экспериментальная версия 0.1.0. Предварительная сборка игры или `.hmod` в релиз не входят: проект нужно собрать через Horizon Launcher.

## Возможности

- Команда `/autofish` включает и выключает режим; при запуске игры он выключен.
- При серверном событии поклёвки мод ставит в очередь обычное нажатие «использовать предмет», чтобы вытащить улов.
- После вытаскивания удочки мод ждёт 4 игровых тика и ставит в очередь следующий обычный клик для заброса.
- Для взаимодействия используется штатный ввод Horizon. Мод не формирует собственные игровые пакеты, не обходит серверные проверки и не создаёт предметы.

Пока авто-рыбалка включена, держи удочку выбранной и направь взгляд на воду. Выключение режима также отменяет ожидающие клики.

## Требования

- Horizon Launcher и инстанс Horizon для Minecraft 26.3.
- Windows, macOS или Linux — настольные платформы, на которых Horizon поддерживает native-build.
- Сборка должна соответствовать закреплённой в `horizon-mod.toml` ревизии Horizon. Если лаунчер сообщает, что ревизия недоступна или несовместима, не меняй pin наугад: сначала обнови проект под установленную сборку.

Launcher использует свой Rust toolchain для native-модов; обычно отдельно устанавливать Rust для самой сборки не требуется.

## Установка из исходников

1. Скачай или клонируй этот проект на компьютер.
2. Открой терминал в папке проекта — там должны лежать `horizon-mod.toml` и `Cargo.toml`.
3. Запусти сборку:

   ```sh
   horizon-launcher native-build . --trust-native-code
   ```

4. Дождись завершения сборки, запусти выбранный инстанс Horizon, зайди в мир и введи `/autofish`.

После изменения исходников снова выполни `native-build`. Первая сборка может занять заметное время. На Windows команду можно запустить из PowerShell, находясь в каталоге проекта.

## Совместимость и ограничения

Сигнал поклёвки (`player_fish`) приходит с серверной стороны игры. Поэтому основной сценарий для этой версии — одиночный мир Horizon. На мультиплеерном сервере, который не запускает этот native-мод, необходимое серверное событие может не прийти: в таком случае авто-вытягивание и автоматический повторный заброс не сработают. Это ограничение не отключает штатную ручную рыбалку.

Horizon Launcher рассчитан на Windows, macOS и Linux; Android и Bedrock не поддерживаются. Мод не предназначен для Fabric, Forge или NeoForge.

## Сборка релиза

Релиз `v0.1.0` — исходный экспериментальный релиз. Готового игрового бинарника нет: Horizon собирает native-мод локально на компьютере пользователя. Исходный проект из релиза нужно распаковать, открыть его папку в терминале и выполнить команду `horizon-launcher native-build . --trust-native-code`.

## Безопасность

Native-мод — исполняемый Rust-код с правами пользователя, а не песочница. `--trust-native-code` разрешает Horizon Launcher собирать и запускать его. Перед сборкой проверяй исходники и не разрешай запуск кода, которому не доверяешь.

## Структура проекта

- `horizon-mod.toml` — имя, версия, сторона запуска и точные pins Horizon/API.
- `Cargo.toml` — зависимость от Mod API из SDK закреплённой сборки.
- `src/lib.rs` — переключатель `/autofish`, обработка поклёвки и очередь обычного ввода.
