# Citrus AutoFish для Horizon

Авто-рыбалка для **Horizon** — реализации Minecraft: Java Edition 26.3, переписанной на Rust. Мод использует собственный native API Horizon. Это **не** Fabric/Forge-мод, не Bedrock-addon и не мод для обычного Java-клиента.

> **Версия 0.1.1 — экспериментальная.** Нужен исходный проект из этой версии: архив `v0.1.0` был в новом формате проекта и не распознаётся Horizon Launcher 0.2.69.

## Возможности

- Введите `/autofish`, чтобы включить или выключить режим; по умолчанию он выключен.
- При серверном событии поклёвки мод ставит в очередь обычный игровой клик для вытягивания удочки.
- После вытягивания ждёт 4 игровых тика, затем ставит в очередь клик для нового заброса.
- Используется штатный ввод Horizon — мод не формирует игровые пакеты самостоятельно и не создаёт предметы.

Пока режим включён, держите удочку выбранной и смотрите на воду. При выключении ожидающие клики сбрасываются.

## Требования

- Horizon Launcher **0.2.69** для Minecraft: Java Edition 26.3.
- Windows, macOS или Linux. Horizon Launcher не поддерживает Android/Bedrock.
- Этот исходный проект `mixins/citrus_autofish`, содержащий `horizon-mixin.toml`.

## Установка через Horizon Launcher 0.2.69

1. Скачайте и распакуйте исходный ZIP релиза `v0.1.1`.
2. В PowerShell перейдите в распакованную папку проекта — ту, где находится этот `README.md`.
3. Запустите native build, передав лаунчеру **папку мода**, а не корень репозитория:

   ```powershell
   & "C:\Users\ADMIN\AppData\Local\Programs\Horizon Launcher\horizon-launcher.exe" native-build .\mixins\citrus_autofish --trust-native-code
   ```

   Если лаунчер установлен в другом месте, замените путь к `horizon-launcher.exe` на свой. Важно оставить `&`, кавычки и путь `mixins\citrus_autofish`.

4. После сборки запустите выбранный инстанс Horizon, войдите в мир и введите `/autofish`.

При изменении исходников запустите эту же команду ещё раз. Первая сборка может занять заметное время. Для Bash/Linux/macOS из корня проекта команда выглядит так:

```sh
horizon-launcher native-build ./mixins/citrus_autofish --trust-native-code
```

## Совместимость и ограничения

Сигнал поклёвки приходит с серверной стороны игры. Главный сценарий этой версии — одиночный мир Horizon. На удалённом vanilla-сервере серверное событие может быть недоступно, поэтому авто-вытягивание и повторный заброс могут не работать. Ручная рыбалка при этом остаётся доступна.

Мод закреплён за конкретной ревизией Horizon в `horizon-mixin.toml`; это нужно для сборки native API. Не меняйте pin вручную.

## Безопасность

Native-мод — исполняемый Rust-код с правами пользователя, а не песочница. Флаг `--trust-native-code` разрешает лаунчеру собрать и запустить его. Перед сборкой проверяйте исходники и не разрешайте запуск кода, которому не доверяете.

## Структура

- `mixins/citrus_autofish/horizon-mixin.toml` — manifest мода; он нужен CLI Horizon Launcher 0.2.69.
- `mixins/citrus_autofish/engine/Cargo.toml` — typed native API и pin исходников Horizon.
- `mixins/citrus_autofish/engine/src/lib.rs` — переключение режима, события рыбалки и штатные клики.
- `compatibility.json` — pins игры, Horizon и mod API.
