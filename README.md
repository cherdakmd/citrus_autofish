# Citrus AutoFish для Horizon

Авто-рыбалка и автоматическая смена удочки для **Horizon** — реализации Minecraft: Java Edition на Rust. Это native-мод Horizon, а не Fabric/Forge-мод, не Bedrock-addon и не игра Rust.

## Возможности v0.3.0

- Команды `/autofish` и `/.autofish` переключают режим. Также принимаются `on`, `off`, `toggle`, `menu`, `settings` и `help`.
- Без слеша, в обычном поле чата, команда `.autofish` тоже перехватывается локально; она не отправляется серверу как сообщение.
- **Right Shift** открывает и закрывает экран настроек; меню также открывается через `/autofish menu` или `.autofish menu`.
- Настройки доступны и на стандартной странице native-мода в разделе **Моды** Horizon, сохраняются между запусками.
- Настраиваются AutoFish, автосмена удочки, безопасный возврат после выуживания, остановка без запасной удочки, порог прочности (1/2/4/8/16/32) и задержка перезаброса (2/4/6/8 тиков).
- По умолчанию мод ищет в хотбаре запасную ванильную удочку с наибольшим остатком прочности и переключается, когда текущей остаётся 8 единиц из 64.
- Если безопасной запасной удочки нет, AutoFish по умолчанию выключается, чтобы не продолжать ловить на удочку в опасном диапазоне.
- После выуживания мод возвращается на прежнюю удочку только если она уже вышла из опасного диапазона; иначе остаётся на запасной, чтобы не сломать прежнюю удочку.

## Установка / обновление через Horizon Launcher

1. Скачай `citrus_autofish-0.3.0.hnmod` из [репозитория](https://github.com/cherdakmd/citrus_autofish/blob/93f8268/release-assets/citrus_autofish-0.3.0.hnmod) через **Download raw file**. Удали старые файлы Citrus AutoFish из `horizon-native-mods` нужного инстанса и положи туда `.hnmod`. Папку можно открыть из раздела модов Launcher. Не клади туда `.hmod`: Horizon Launcher 0.2.69 не распознаёт этот комбинированный пакет в папке native-модов.
2. Включи Citrus AutoFish в списке модов.
3. Нажми **«Собрать»**. После успешной сборки запусти тот же инстанс.
4. В игре введи `/autofish` или `.autofish`; меню — `/autofish menu` или `.autofish menu`.

Native-мод — исполняемый Rust-код с правами пользователя. Перед сборкой исходников проверяй их; `--trust-native-code` разрешает Launcher собирать и запускать такой код.

## Совместимость и примечания

- Minecraft: Java Edition 26.3; Horizon Launcher 0.2.69.
- Horizon revision `9f42064c11efe7ef3e5ed2baad7ddc2a3b36eea0`.
- Native hooks API: 415; Horizon mixins revision: `0d6b103c70633d8fd9443d8d0acd3aadaacedb06`.
- Авто-рыбалка отправляет `UseItem` напрямую, потому что используемый API Horizon не предоставляет очередь vanilla `key.use`. Это экспериментальный путь; sequence counter не синхронизирован с внутренним счётчиком Horizon. Если замечаешь проблемы с подтверждением действий, отключи AutoFish.
- Смена удочки отслеживает ванильную `fishing_rod` по пакетам хотбара; на сетевых серверах её поведение зависит от синхронизации инвентаря и ограничений сервера.
- Проверяй новые версии сначала в одиночном или тестовом мире. Не используй мод на сервере, если его правила запрещают автоматизацию.
