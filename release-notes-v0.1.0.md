## Citrus AutoFish v0.1.0 — экспериментальный исходный релиз

Нативный мод авто-рыбалки для Horizon — Minecraft: Java Edition 26.3, переписанного на Rust. Это не Fabric/Forge-мод и не Bedrock-addon.

### Возможности

- Введите `/autofish` в игре, чтобы включить или выключить автоматизацию.
- После серверного события поклёвки мод ставит в очередь обычный игровой клик для вытягивания удочки.
- После вытягивания ждёт 4 игровых тика, затем ставит в очередь клик для нового заброса.
- Мод использует штатный ввод Horizon; игровые пакеты вручную не формирует.

### Установка

1. Скачайте исходный ZIP этого релиза и распакуйте его на Windows, macOS или Linux.
2. Откройте терминал в папке проекта — в ней должны быть `horizon-mod.toml` и `Cargo.toml`.
3. Выполните `horizon-launcher native-build . --trust-native-code`.
4. Запустите собранный инстанс, войдите в мир и введи `/autofish`.

Первоначальная сборка может занять время. После изменения исходников запустите `native-build` повторно.

### Совместимость и ограничения

Проект закреплён за Horizon 26.3 и точной ревизией, указанной в `horizon-mod.toml`. Основной сценарий — одиночный мир. Для автоматизации требуется серверное событие поклёвки; на удалённом vanilla-сервере оно может быть недоступно. Оставляйте удочку выбранной. Horizon Launcher рассчитан на настольные Windows, macOS и Linux.

### Важно

Это экспериментальный prerelease. В релизе находятся исходники проекта, а не скомпилированный бинарник или готовый `.hmod`; сборка выполняется локально через Horizon Launcher. End-to-end сборка и игровой тест для этого релиза не запускались. Нативные моды выполняются с правами пользователя и не изолированы песочницей: изучите исходный код перед разрешением `--trust-native-code`.
