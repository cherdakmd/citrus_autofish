# Citrus AutoFish v0.2.0

- Добавлен экран настроек, открываемый `/autofish menu` и Right Shift.
- Настройки включают AutoFish, автосмену удочки, порог прочности и безопасный возврат к предыдущей ячейке хотбара.
- Настройки доступны также на стандартной странице native-мода Horizon и сохраняются лаунчером.
- Автосмена ищет запасную ванильную удочку среди 9 ячеек хотбара и выбирает вариант с наибольшим остатком прочности. Порог по умолчанию — 8 единиц из 64.
- Возврат к прежней удочке после выуживания происходит только если она вышла из опасного диапазона; иначе мод остаётся на запасной.
- Используется API native hooks 415 и Horizon revision `9f42064c11efe7ef3e5ed2baad7ddc2a3b36eea0`.

Авто-рыбалка по-прежнему отправляет `UseItem` напрямую и остаётся экспериментальной. Сборка новой версии и проверка в игре должны быть выполнены в Horizon Launcher.
